# Python DA Assignment 1: Data Analysis using NumPy and Pandas

## Project Overview

This repository contains my first Python Data Analytics assignment, focusing on learning and practicing NumPy and Pandas for data analysis.

The assignment covers creating arrays and Series, performing data operations, exploring datasets, and manipulating DataFrames using Python.

## Topics Covered

### 1. NumPy Array Operations
- Creating 1D and 2D NumPy arrays
- Inspecting array properties such as shape, data type, and size
- Converting temperatures from Celsius to Fahrenheit
- Calculating maximum, minimum, and mean values
- Array indexing and slicing
- Extracting weekly and weekend temperature data

### 2. Pandas Series
- Creating Pandas Series with custom indices
- Accessing elements using integer indexing
- Indexing and slicing using `loc` and `iloc`
- Filtering data using Boolean masks
- Updating and deleting Series elements
- Calculating CGPA from marks

### 3. Pandas DataFrame
- Creating DataFrames using dictionaries
- Exploring data using `head()`, `tail()`, `shape`, `columns`, and `dtypes`
- Selecting specific columns
- Filtering rows using conditions
- Finding unique values and value counts
- Grouping data and calculating mean values
- Adding, updating, and deleting rows and columns

## Tools and Technologies

- Python

## Dataset Description

This assignment uses two sample datasets:

**1. Temperature Data**
